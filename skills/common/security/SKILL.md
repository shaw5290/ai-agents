## 安全规范

- 禁止将密码、密钥、Token 写入代码或提交到仓库；使用环境变量或配置中心。
- 所有外部输入在服务端校验，不信任前端校验结果。
- 权限校验在服务端完成；接口按最小权限设计。
- 密码加盐哈希后存储；API 响应中的敏感字段脱敏。
- **ALWAYS**：SQL 总是使用参数化查询，禁止拼接用户输入，防止 SQL 注入。
- **NEVER**：日志中永远不打印密码、Token、身份证号、手机号等敏感信息，必要时脱敏。
